# Node Example

This sample is a small Express application that stores submitted form data in `data/data.json`.

## Run Without Docker

### Required Tools
- Node.js 14+ and `npm`

### Start Locally
```bash
cd Docker/example-projects/node
npm install
npm start
```

Open http://localhost:3000

## Notes
- The app creates `data/data.json` automatically on first run.
- This example is useful to show the "before Docker" experience: install runtime, install dependencies, then start the app.
